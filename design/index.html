走马灯Zoetrope — 把整部手机,变成一只暗房抽屉

大图优先的个人看图 App。打开即全屏,左右滑切图,侧滑抽屉换文件夹; 灵魂功能随机幻灯片——洗牌算法保证一轮不重复,像暗房里随机显影一张旧底片。 下面这台"手机"是可交互的:试试滑动、按 空格、或点那个红色的放映键。

STACK Kotlin · Compose SOURCE MediaStore SCALE 1–5 万张 BUILD GitHub Actions
01大图优先

打开即全屏看图,无相册网格挡路。启动首图可配置:接着上次看 / 随机 / 固定文件夹 / 最新,默认接着上次看;首次启动没有「上次」,回退随机一张。

02侧滑抽屉

左缘滑出文件夹列表(封面 + 张数),点选即跳。行尾 ⊞ 进入"印样"网格做批量管理;不想看的文件夹可隐藏,并自动移出随机池。

03随机幻灯片

Fisher–Yates 洗牌,一轮内零重复;范围随抽屉选择。底栏 ▶ / ⏸ 一键开始、暂停、恢复,放映中轻点图片同样暂停/恢复;间隔 3s / 5s / 10s 在设置里调,播完自动重洗。计数器实时显示"已显影 n / N"。

04收藏与隐藏

看图时点心形收藏,收藏夹本身就是一个随机范围;文件夹可隐藏、单张可长按「不再显示」,双双移出随机池,但文件永远不动。

05安全删除

删除走系统回收站机制,可恢复;另有批量管理、EXIF 元信息面板。示例图均为程序生成的"底片",实机将扫描真实照片。

05

共识清单

v1 SCOPE · FROM GRILL-ME
[✓]随机幻灯片

洗牌零重复 + 底栏播放/暂停 + 轻点图片暂停 + 播完重洗。灵魂功能。

[✓]大图优先浏览

全屏为主界面,启动首图可配置,默认"接着上次看"。

[✓]文件夹抽屉

MediaStore 按目录分组,混合来源统一为文件夹视图。

[✓]收藏 + 收藏内随机

心形一键收藏,收藏即随机池。

[✓]隐藏文件夹

表情包、图标缓存不再污染随机池,随时可恢复。

[✓]安全删除

回收站机制,误删可救,toast 一键撤销。

[✓]批量管理

印样网格多选删除/移动(示意入口,交互同系统相册)。

[✓]图片信息

拍摄时间、分辨率、路径、EXIF 一屏读完。

[✓]纯看图 · 无视频

MediaStore 只取图片,随机池/网格/信息面板均不含视频。

[✓]单张不再显示

长按 0.5s 移出随机池,文件不动;抽屉「已忽略」可随时恢复。

[✓]双击 + 捏合缩放

双击 1x↔2.5x,捏合连续缩放,拖动看局部。

[✓]参数自动记住

速度 / 范围 / 播完行为跨启动记忆,零设置项。

[✓]首启流程

权限说明屏 → 扫描 → 随机一张开场(无「上次」可接);拒绝授权给空状态与重试。数据源唯一 = 手机相册(MediaStore),无导入;部分授权时随机池仅含已选照片并提示放开。
